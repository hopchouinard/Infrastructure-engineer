## 4. Testing Approach

### 4.1 Testing Philosophy

SubAgents are **instruction-based** (markdown files), not code. Testing focuses on:

1. **Behavioral Testing**: Does the agent behave correctly?
2. **Constraint Testing**: Does the agent respect permissions?
3. **Output Testing**: Does the agent produce correct output formats?
4. **Integration Testing**: Does the agent work with other components?

### 4.2 Testing Methodology

Since agents are LLM-driven, testing is primarily:

- **Manual Execution**: Run scenarios in Claude Code
- **Checklist Verification**: Confirm behavior against checklist
- **Output Comparison**: Verify output matches expected format
- **Constraint Verification**: Confirm prohibited actions don't occur

## 6. Test Execution Guidelines

### 6.1 Test Environment Setup

1. Start fresh Claude Code session
2. Navigate to project directory
3. Verify MCP server is accessible
4. Have test data ready (or use mock)

### 6.2 Running Tests

For each test:
1. Clear previous context if needed
2. Enter the test prompt exactly
3. Observe agent response
4. Check against expected results
5. Record Pass/Fail with notes

### 6.3 Handling Failures

When a test fails:
1. Record the actual behavior
2. Compare to expected
3. Identify if it's agent issue or test issue
4. Document fix needed
5. Re-test after fix
