# F2.9: MCP Integration

## Objective

Integrate all components into a functional MCP server that can be used by Claude Code, including tool registration, server lifecycle, and Claude Code configuration.

## Prerequisites

- F2.1-F2.8 all completed
- MCP SDK available (`mcp>=1.0.0`)

## Scope

### In Scope

- MCP server setup using FastMCP
- Tool registration with decorators
- Server lifecycle management with lifespan
- Claude Code configuration
- Connection handling

### Out of Scope

- MCP authentication (handled by protocol)
- Custom MCP extensions

## Implementation Requirements

### 1. Server Implementation

The MCP Python SDK provides two approaches:
- **FastMCP** (recommended): High-level, decorator-based, minimal boilerplate
- **Low-level Server**: More control, more verbose

We use **FastMCP** for simplicity and maintainability.

**File: `mcp-servers/unifi-mcp/src/unifi_mcp/server.py`**

```python
"""
MCP Server entry point for UniFi operations.

Uses FastMCP for a clean, decorator-based approach to tool registration.
See: https://github.com/modelcontextprotocol/python-sdk
"""

from __future__ import annotations

import json
import logging
import time
from contextlib import asynccontextmanager
from typing import Any, AsyncIterator

from mcp.server.fastmcp import FastMCP

from unifi_mcp.config import UniFiConfig
from unifi_mcp.client import UniFiClient
from unifi_mcp.safety import ValidationEngine, RateLimiter, RateLimitConfig
from unifi_mcp.safety.rollback import RollbackManager
from unifi_mcp.logging.audit import AuditLogger, create_audit_entry

logger = logging.getLogger(__name__)

# Global state managed by lifespan
_state: dict[str, Any] = {}


@asynccontextmanager
async def lifespan(server: FastMCP) -> AsyncIterator[dict[str, Any]]:
    """
    Manage server lifecycle - connect to UniFi on startup, disconnect on shutdown.

    The lifespan context manager is called once when the server starts and
    provides shared state to all tool handlers via the context.
    """
    config = UniFiConfig()

    # Configure logging
    logging.basicConfig(
        level=getattr(logging, config.log_level),
        format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    )

    logger.info("Starting UniFi MCP server")
    logger.info(f"Controller: {config.unifi_host}")
    logger.info(f"Site: {config.unifi_site}")
    logger.info(f"Dry run: {config.dry_run}")

    # Initialize components
    client = UniFiClient(config)
    validation = ValidationEngine(config)
    rollback = RollbackManager(config.rollback_retention_minutes)
    rate_limiter = RateLimiter(
        RateLimitConfig(max_requests=config.max_changes_per_minute)
    )
    audit = AuditLogger(config.audit_log_path) if config.enable_audit_log else None

    # Connect to UniFi controller
    try:
        await client.connect()
        if await client.test_connection():
            logger.info("Successfully connected to UniFi controller")
        else:
            logger.error("Failed to connect to UniFi controller")
            raise RuntimeError("UniFi connection test failed")
    except Exception as e:
        logger.error(f"Failed to connect: {e}")
        raise

    # Provide state to tools
    state = {
        "config": config,
        "client": client,
        "validation": validation,
        "rollback": rollback,
        "rate_limiter": rate_limiter,
        "audit": audit,
    }

    try:
        yield state
    finally:
        # Cleanup on shutdown
        logger.info("Shutting down UniFi MCP server")
        await client.disconnect()


# Create the FastMCP server with lifespan
mcp = FastMCP(
    "unifi-mcp",
    lifespan=lifespan,
)

# Middleware Helpers
# =============================================================================

async def check_rate_limit() -> str | None:
    """
    Check if rate limit allows this operation.

    Returns:
        None if allowed, error message string if rate limited
    """
    ctx = mcp.get_context()
    rate_limiter = ctx.state["rate_limiter"]

    if not await rate_limiter.acquire():
        retry_after = rate_limiter.retry_after()
        return json.dumps({
            "success": False,
            "error": f"Rate limit exceeded. Retry after {retry_after} seconds.",
            "retry_after": retry_after,
        })
    return None


async def log_audit(
    tool_name: str,
    permission_tier: str,
    params: dict,
    result: dict,
    duration_ms: int,
    dry_run: bool,
) -> None:
    """Log an operation to the audit log if enabled."""
    ctx = mcp.get_context()
    audit = ctx.state["audit"]

    if audit:
        entry = create_audit_entry(
            tool_name=tool_name,
            permission_tier=permission_tier,
            params=params,
            result=result,
            duration_ms=duration_ms,
            dry_run=dry_run,
        )
        await audit.log(entry)

@mcp.tool()
async def unifi_list_networks(
    include_default: bool = True,
    vlan_only: bool = False,
) -> str:
    """
    List all networks/VLANs configured on the UniFi controller.

    Args:
        include_default: Include the default network (default: True)
        vlan_only: Only return networks with VLAN IDs (default: False)

    Returns:
        JSON list of networks with id, name, vlan_id, subnet, and dhcp status
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]

    response = await client.get("/rest/networkconf")
    networks = response.get("data", [])

    result = []
    for net in networks:
        if vlan_only and not net.get("vlan"):
            continue
        if not include_default and net.get("name", "").lower() == "default":
            continue

        result.append({
            "id": net.get("_id"),
            "name": net.get("name"),
            "vlan_id": net.get("vlan"),
            "subnet": net.get("ip_subnet"),
            "purpose": net.get("purpose"),
            "dhcp_enabled": net.get("dhcpd_enabled", False),
        })

    return json.dumps({"success": True, "data": result}, indent=2)


@mcp.tool()
async def unifi_get_network(identifier: str) -> str:
    """
    Get details for a specific network by name, ID, or VLAN ID.

    Args:
        identifier: Network name, ID, or VLAN ID

    Returns:
        JSON object with network details
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]

    response = await client.get("/rest/networkconf")
    identifier_lower = identifier.lower()

    for net in response.get("data", []):
        if (net.get("name", "").lower() == identifier_lower or
            net.get("_id") == identifier or
            str(net.get("vlan")) == identifier):
            return json.dumps({"success": True, "data": net}, indent=2)

    return json.dumps({"success": False, "error": f"Network not found: {identifier}"})


@mcp.tool()
async def unifi_list_clients(
    connected_only: bool = True,
    network: str | None = None,
) -> str:
    """
    List clients on the network.

    Args:
        connected_only: Only show currently connected clients (default: True)
        network: Filter by network name (optional)

    Returns:
        JSON list of clients with mac, ip, hostname, and connection info
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]

    endpoint = "/stat/sta" if connected_only else "/stat/alluser"
    response = await client.get(endpoint)
    clients = response.get("data", [])

    result = []
    for c in clients:
        if network and c.get("network", "").lower() != network.lower():
            continue

        result.append({
            "mac": c.get("mac"),
            "ip": c.get("ip"),
            "hostname": c.get("hostname"),
            "name": c.get("name"),
            "network": c.get("network"),
            "is_wired": c.get("is_wired", False),
            "is_guest": c.get("is_guest", False),
        })

    return json.dumps({"success": True, "data": result, "count": len(result)}, indent=2)


@mcp.tool()
async def unifi_list_devices() -> str:
    """
    List all UniFi devices (APs, switches, gateways).

    Returns:
        JSON list of devices with name, mac, ip, model, and status
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]

    response = await client.get("/stat/device")
    devices = response.get("data", [])

    result = []
    for d in devices:
        result.append({
            "name": d.get("name"),
            "mac": d.get("mac"),
            "ip": d.get("ip"),
            "model": d.get("model"),
            "type": d.get("type"),
            "state": "online" if d.get("state") == 1 else "offline",
            "version": d.get("version"),
        })

    return json.dumps({"success": True, "data": result}, indent=2)


@mcp.tool()
async def unifi_list_firewall_rules(ruleset: str | None = None) -> str:
    """
    List firewall rules.

    Args:
        ruleset: Filter by ruleset (LAN_IN, LAN_OUT, WAN_IN, etc.)

    Returns:
        JSON list of firewall rules
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]

    response = await client.get("/rest/firewallrule")
    rules = response.get("data", [])

    if ruleset:
        rules = [r for r in rules if r.get("ruleset") == ruleset]

    result = []
    for r in rules:
        result.append({
            "id": r.get("_id"),
            "name": r.get("name"),
            "enabled": r.get("enabled", True),
            "ruleset": r.get("ruleset"),
            "action": r.get("action"),
            "protocol": r.get("protocol"),
        })

    return json.dumps({"success": True, "data": result}, indent=2)

@mcp.tool()
async def unifi_create_network(
    name: str,
    vlan_id: int,
    subnet: str,
    purpose: str = "corporate",
    dhcp_enabled: bool = True,
) -> str:
    """
    Create a new VLAN/network. Requires confirmation. (MEDIUM permission tier)

    Args:
        name: Network name (1-32 characters)
        vlan_id: VLAN ID (2-4094)
        subnet: CIDR notation (e.g., 192.168.10.0/24)
        purpose: Network purpose (corporate, guest, vlan-only)
        dhcp_enabled: Enable DHCP server (default: True)

    Returns:
        JSON result with network ID and rollback info
    """
    import ipaddress

    # Rate limit check (MEDIUM and higher operations)
    rate_error = await check_rate_limit()
    if rate_error:
        return rate_error

    ctx = mcp.get_context()
    config = ctx.state["config"]
    client = ctx.state["client"]
    rollback = ctx.state["rollback"]

    start_time = time.perf_counter()

    # Validate VLAN ID
    if not 2 <= vlan_id <= 4094:
        return json.dumps({"success": False, "error": "VLAN ID must be between 2 and 4094"})

    # Validate subnet
    try:
        network = ipaddress.ip_network(subnet, strict=False)
    except ValueError as e:
        return json.dumps({"success": False, "error": f"Invalid subnet: {e}"})

    # Check if VLAN already exists
    existing = await client.get("/rest/networkconf")
    for net in existing.get("data", []):
        if net.get("vlan") == vlan_id:
            return json.dumps({"success": False, "error": f"VLAN {vlan_id} already exists"})
        if net.get("name", "").lower() == name.lower():
            return json.dumps({"success": False, "error": f"Network '{name}' already exists"})

    # Dry run check
    if config.dry_run:
        return json.dumps({
            "success": True,
            "dry_run": True,
            "message": f"[DRY RUN] Would create network '{name}' (VLAN {vlan_id})",
        }, indent=2)

    # Build network config
    hosts = list(network.hosts())
    net_config = {
        "name": name,
        "vlan": vlan_id,
        "vlan_enabled": True,
        "ip_subnet": subnet,
        "purpose": purpose,
        "dhcpd_enabled": dhcp_enabled,
        "networkgroup": "LAN",
    }

    if dhcp_enabled and len(hosts) > 10:
        net_config["dhcpd_start"] = str(hosts[10])
        net_config["dhcpd_stop"] = str(hosts[-2])

    # Create network
    try:
        result = await client.post("/rest/networkconf", net_config)

        if result.get("meta", {}).get("rc") == "ok":
            network_id = result["data"][0]["_id"]

            # Record rollback
            rollback_id = await rollback.record(
                action="create_network",
                undo_action="delete_network",
                undo_params={"network_id": network_id},
                description=f"Created network '{name}'",
            )

            # Audit log
            duration_ms = int((time.perf_counter() - start_time) * 1000)
            await log_audit(
                tool_name="unifi_create_network",
                permission_tier="MEDIUM",
                params={"name": name, "vlan_id": vlan_id, "subnet": subnet},
                result={"success": True, "network_id": network_id},
                duration_ms=duration_ms,
                dry_run=False,
            )

            return json.dumps({
                "success": True,
                "data": {"id": network_id, "name": name, "vlan_id": vlan_id},
                "message": f"Created network '{name}' (VLAN {vlan_id})",
                "rollback_id": rollback_id,
            }, indent=2)

        return json.dumps({"success": False, "error": "API returned error"})

    except Exception as e:
        return json.dumps({"success": False, "error": str(e)})


@mcp.tool()
async def unifi_delete_network(identifier: str) -> str:
    """
    Delete a network/VLAN. Requires confirmation. HIGH risk operation.

    Args:
        identifier: Network name, ID, or VLAN ID

    Returns:
        JSON result with rollback info
    """
    ctx = mcp.get_context()
    config = ctx.state["config"]
    client = ctx.state["client"]
    rollback = ctx.state["rollback"]

    # Find network
    response = await client.get("/rest/networkconf")
    target = None
    identifier_lower = identifier.lower()

    for net in response.get("data", []):
        if (net.get("name", "").lower() == identifier_lower or
            net.get("_id") == identifier or
            str(net.get("vlan")) == identifier):
            target = net
            break

    if not target:
        return json.dumps({"success": False, "error": f"Network not found: {identifier}"})

    # Safety checks
    if target.get("purpose") == "wan":
        return json.dumps({"success": False, "error": "Cannot delete WAN network"})
    if target.get("name", "").lower() == "default":
        return json.dumps({"success": False, "error": "Cannot delete default network"})

    # Check for connected clients
    clients = await client.get("/stat/sta")
    network_id = target["_id"]
    connected = sum(1 for c in clients.get("data", []) if c.get("network_id") == network_id)

    if connected > 0:
        return json.dumps({
            "success": False,
            "error": f"Network has {connected} connected client(s) - disconnect them first"
        })

    # Dry run
    if config.dry_run:
        return json.dumps({
            "success": True,
            "dry_run": True,
            "message": f"[DRY RUN] Would delete network '{target['name']}'",
        }, indent=2)

    # Store for rollback
    rollback_id = await rollback.record(
        action="delete_network",
        undo_action="create_network",
        undo_params={"config": target},
        description=f"Deleted network '{target['name']}'",
    )

    # Delete
    try:
        result = await client.delete(f"/rest/networkconf/{target['_id']}")

        if result.get("meta", {}).get("rc") == "ok":
            return json.dumps({
                "success": True,
                "message": f"Deleted network '{target['name']}'",
                "rollback_id": rollback_id,
            }, indent=2)

        return json.dumps({"success": False, "error": "API returned error"})

    except Exception as e:
        return json.dumps({"success": False, "error": str(e)})


@mcp.tool()
async def unifi_block_client(mac: str) -> str:
    """
    Block a client from accessing the network. Requires confirmation.

    Args:
        mac: Client MAC address

    Returns:
        JSON result with rollback info
    """
    ctx = mcp.get_context()
    config = ctx.state["config"]
    client = ctx.state["client"]
    rollback = ctx.state["rollback"]

    mac = mac.lower()

    if config.dry_run:
        return json.dumps({
            "success": True,
            "dry_run": True,
            "message": f"[DRY RUN] Would block client {mac}",
        }, indent=2)

    try:
        result = await client.post("/cmd/stamgr", {
            "cmd": "block-sta",
            "mac": mac,
        })

        if result.get("meta", {}).get("rc") == "ok":
            rollback_id = await rollback.record(
                action="block_client",
                undo_action="unblock_client",
                undo_params={"mac": mac},
                description=f"Blocked client {mac}",
            )

            return json.dumps({
                "success": True,
                "message": f"Blocked client {mac}",
                "rollback_id": rollback_id,
            }, indent=2)

        return json.dumps({"success": False, "error": "API returned error"})

    except Exception as e:
        return json.dumps({"success": False, "error": str(e)})


@mcp.tool()

@mcp.tool()
async def unifi_undo(rollback_id: str | None = None, list_available: bool = False) -> str:
    """
    Undo a previous configuration change or list available rollbacks.

    Args:
        rollback_id: ID of the rollback to execute (from previous operation)
        list_available: If True, list available rollbacks instead of executing

    Returns:
        JSON result of undo operation or list of available rollbacks
    """
    ctx = mcp.get_context()
    client = ctx.state["client"]
    rollback = ctx.state["rollback"]

    if list_available:
        available = rollback.list_available()
        return json.dumps({
            "success": True,
            "data": available,
            "message": f"Found {len(available)} available rollback(s)",
        }, indent=2)

    if not rollback_id:
        return json.dumps({
            "success": False,
            "error": "rollback_id required (or use list_available=True)",
        })

    result = await rollback.undo(rollback_id, client)
    return json.dumps(result, indent=2)

## Architecture Notes

### FastMCP vs Low-Level Server

| Aspect | FastMCP (Used) | Low-Level Server |
|--------|----------------|------------------|
| Boilerplate | Minimal - decorators | Manual setup |
| Schema | Auto-generated from types | Manual definition |
| State Management | Lifespan context | Manual |
| Recommended For | Most use cases | Custom protocols |

### Tool Categories and Permissions

| Category | Permission | Confirmation | Examples |
|----------|------------|--------------|----------|
| Query | READ | None | list_networks, list_clients |
| Config | MEDIUM | Brief | create_network, block_client |
| Destructive | HIGH | Explicit + rollback | delete_network |

### State Flow

```

│                         lifespan()                               │
