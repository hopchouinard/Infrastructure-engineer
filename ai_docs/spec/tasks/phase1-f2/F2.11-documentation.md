# UniFi MCP Server

A Model Context Protocol (MCP) server that allows Claude Code to manage your UniFi network infrastructure.

## Features

- **Query Operations**: List networks, clients, devices, firewall rules
- **Configuration**: Create/update/delete VLANs, firewall rules
- **Safety**: Permission tiers, dry-run mode, rollback capability
- **Audit Trail**: Comprehensive logging of all operations

## Quick Start

### Prerequisites

- Python 3.11+
- UniFi controller access (UDM, UDR, or Cloud Key)
- API user credentials

### Installation

```bash
cd mcp-servers/unifi-mcp
pip install -e ".[dev]"
```

### Configuration

Create a `.env` file:

```bash
UNIFI_HOST=https://192.168.1.1
UNIFI_USERNAME=api-user
UNIFI_PASSWORD=your-password
UNIFI_SITE=default
```

### Claude Code Integration

Add to your Claude Code settings (`.claude/settings.json`):

```json
{
  "mcpServers": {
    "unifi": {
      "command": "python",
      "args": ["-m", "unifi_mcp.server"],
      "cwd": "/path/to/mcp-servers/unifi-mcp",
      "env": {
        "UNIFI_HOST": "https://192.168.1.1",
        "UNIFI_USERNAME": "api-user",
        "UNIFI_PASSWORD": "${UNIFI_PASSWORD}"
      }
    }
  }
}
```

### Usage Examples

With Claude Code:

```
You: List all VLANs on my network
Claude: [Uses unifi_list_networks tool]
Found 3 networks:
- Default (VLAN 1): 192.168.1.0/24
- IoT (VLAN 10): 192.168.10.0/24

## Safety Features

### Permission Tiers

- **READ**: Auto-approved (queries)
- **LOW**: Brief confirmation (rename)
- **MEDIUM**: Detailed confirmation (create VLAN)
- **HIGH**: Explicit confirmation + rollback info (firewall)
- **CRITICAL**: User-initiated only

### Dry Run Mode

Enable with `DRY_RUN=true` to preview changes without applying them.

### Rollback

Configuration changes can be undone within the retention period:

```
You: Undo the last change
Claude: [Uses unifi_undo with rollback_id]
Rolled back: Created network 'Cameras'
```

## Troubleshooting

### Connection Issues

**Error: Cannot connect to UniFi controller**
- Verify `UNIFI_HOST` is correct
- Check network connectivity
- Ensure controller is running

**Error: Authentication failed**
- Verify username/password
- Check user has API access
- Try logging in via browser first

### SSL Certificate Issues

For self-signed certificates:
```bash
UNIFI_VERIFY_SSL=false
```

### Rate Limiting

If you see "Rate limit exceeded":
- Wait 60 seconds
- Reduce `MAX_CHANGES_PER_MINUTE`

# Tool Reference

Complete reference for all UniFi MCP tools.

## Network Tools

### unifi_list_networks

List all networks/VLANs configured on the controller.

**Parameters:**
- `include_default` (boolean, default: true): Include default network
- `vlan_only` (boolean, default: false): Only networks with VLAN IDs

**Example:**
```json
{
  "success": true,
  "data": [
    {
      "id": "abc123",
      "name": "IoT",
      "vlan_id": 10,
      "subnet": "192.168.10.0/24",
      "dhcp_enabled": true
    }
  ]
}
```

### unifi_create_network

Create a new VLAN/network.

**Parameters:**
- `name` (string, required): Network name
- `vlan_id` (integer, required): VLAN ID (2-4094)
- `subnet` (string, required): CIDR notation
- `purpose` (string): "corporate", "guest", "vlan-only"
- `dhcp_enabled` (boolean): Enable DHCP

**Example:**
```json
{
  "name": "IoT Devices",
  "vlan_id": 30,
  "subnet": "192.168.30.0/24",
  "purpose": "corporate",
  "dhcp_enabled": true
}

# Configuration Guide

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `UNIFI_HOST` | Yes | - | UniFi controller URL |
| `UNIFI_USERNAME` | Yes | - | API username |
| `UNIFI_PASSWORD` | Yes | - | API password |
| `UNIFI_SITE` | No | `default` | Site name |
| `UNIFI_VERIFY_SSL` | No | `false` | SSL verification |
| `DRY_RUN` | No | `false` | Preview mode |
| `MAX_CHANGES_PER_MINUTE` | No | `5` | Rate limit |
| `ROLLBACK_RETENTION_MINUTES` | No | `60` | Rollback window |
| `AUDIT_LOG_PATH` | No | `logs/audit.log` | Audit log location |
| `LOG_LEVEL` | No | `INFO` | Logging level |

## Configuration File

Create `config.yaml`:

```yaml
unifi_host: "https://192.168.1.1"
unifi_username: "api-user"
unifi_password: "${UNIFI_PASSWORD}"
unifi_site: "default"

dry_run: false
max_changes_per_minute: 5

profiles:
  development:
    dry_run: true
    log_level: "DEBUG"

  production:
    dry_run: false
    max_changes_per_minute: 3
```

## UniFi API User Setup

1. Open UniFi OS Settings
2. Go to Admins → Add Admin
3. Create local user with:
   - Role: Limited Admin
   - Application: Network (Full)
4. Save credentials securely
```
