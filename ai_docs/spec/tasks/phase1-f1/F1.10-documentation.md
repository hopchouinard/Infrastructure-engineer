# UniFi Documentation Crawler

A Python-based crawler for building an offline corpus of UniFi documentation from official sources.

## Features

- **Help Center Crawling**: Downloads articles from help.ui.com
- **Guides Crawling**: Downloads PDF guides from dl.ubnt.com
- **Incremental Updates**: Only downloads new or changed content
- **Rate Limiting**: Respects server limits and robots.txt
- **Multiple Output Formats**: Converts HTML and PDF to Markdown

## Quick Start

### Installation

```bash
# Clone the repository
cd tools/doc-crawler

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -e ".[dev]"
```

### Basic Usage

```bash
# Crawl all sources
doc-crawler crawl --source all --output ./unifi-docs

# Crawl only Help Center
doc-crawler crawl --source help-center --output ./unifi-docs

# Crawl only PDF guides
doc-crawler crawl --source guides --output ./unifi-docs

# Check crawl status
doc-crawler status --output ./unifi-docs

# Verify downloaded content
doc-crawler verify --output ./unifi-docs
```

## Troubleshooting

### Common Issues

#### Rate Limiting Errors

If you see "429 Too Many Requests" errors:

```bash
# Use lower rate limit
doc-crawler crawl --source all --output ./docs
```

Or in config:

```json
{
  "rate_limit_requests": 5,
  "rate_limit_period": 2.0
}
```

#### Connection Timeouts

Increase timeout for slow connections:

```json
{
  "request_timeout": 60.0,
  "max_retries": 5
}
```

#### Incomplete Crawls

Resume an incomplete crawl:

```bash
# State is automatically saved; just run again
doc-crawler crawl --source all --output ./docs
```

Force complete re-download:

```bash
doc-crawler crawl --source all --output ./docs --force
```

### Logging

Enable debug logging:

```bash
DOC_CRAWLER_LOG_LEVEL=DEBUG doc-crawler crawl --source all -v
```

Logs are written to `crawl.log` in the output directory.

#!/usr/bin/env python3
"""
Custom adapter example.

Shows how to create a custom adapter for a new documentation source.
"""

from dataclasses import dataclass
from typing import AsyncIterator

from doc_crawler.adapters.base import BaseAdapter
from doc_crawler.config import CrawlerConfig
from doc_crawler.fetcher import Fetcher


@dataclass
class CustomItem:
    """Represents a discovered item from the custom source."""

    url: str
    title: str
    category: str


class CustomAdapter(BaseAdapter):
    """
    Custom adapter for a hypothetical documentation source.

    This demonstrates the pattern for adding new sources.
    """

    def __init__(self, fetcher: Fetcher, config: CrawlerConfig):
        super().__init__(fetcher, config)
        self.base_url = "https://docs.example.com"

    async def discover(self) -> AsyncIterator[CustomItem]:
        """Discover items from the documentation source."""
        # Fetch index page
        response = await self.fetcher.get(f"{self.base_url}/index.html")

        # Parse and yield items (simplified)
        # In practice, use BeautifulSoup or similar
        yield CustomItem(
            url=f"{self.base_url}/getting-started",
            title="Getting Started",
            category="basics",
        )

    async def fetch_item(self, item: CustomItem) -> str:
        """Fetch and return content for an item."""
        response = await self.fetcher.get(item.url)
        return response.text


# Usage
async def main():
    from doc_crawler import CrawlerConfig, Fetcher
    from pathlib import Path

    config = CrawlerConfig(output_dir=Path("./custom-docs"))

    async with Fetcher(config) as fetcher:
        adapter = CustomAdapter(fetcher, config)

        async for item in adapter.discover():
            print(f"Found: {item.title}")
            content = await adapter.fetch_item(item)
            print(f"  Content length: {len(content)}")


if __name__ == "__main__":
    import asyncio

    asyncio.run(main())
```

        # Find code blocks without language hints

        bare_blocks = re.findall(r"```\n[^`]", content)
