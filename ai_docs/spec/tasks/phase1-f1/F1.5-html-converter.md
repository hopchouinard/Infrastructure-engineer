## 1. Objective

Implement an HTML to Markdown converter that transforms crawled Help Center articles into clean, readable Markdown with frontmatter metadata.

## 2. Prerequisites

- Task F1.1 (Project Setup) completed
- `html2text` library available (from pyproject.toml)

## 3. Scope

### In Scope
- Convert HTML to Markdown
- Generate YAML frontmatter with metadata
- Preserve code blocks
- Handle tables
- Clean up unnecessary elements (navigation, ads, etc.)
- Handle images (reference only, not download)

### Out of Scope
- PDF conversion (F1.6)
- Image downloading/embedding
- Custom HTML element handling
- Full HTML parsing (beyond conversion)

## 4. Implementation Requirements

### 4.1 Output Format

Each converted article should have this standardized structure optimized for agentic frameworks like Claude Code. The predictable layout enables effective scanning and information extraction.

```markdown
---
source: help.ui.com
url: https://help.ui.com/hc/en-us/articles/123456-Article-Title
title: "Article Title"
original_article_id: "123456"
category_id: "789"
section_id: "456"
topic: "vlans"
keywords:
  - vlan
  - network
  - dhcp
updated_at: "2024-01-15"
crawled_at: "2025-01-09T15:30:00Z"
checksum: "abc123def456..."
---

# Article Title

## Overview

Brief 1-3 sentence summary of what this article covers. This section is ALWAYS present to aid quick relevance assessment.

## Prerequisites

*Optional section - only included if applicable*

- UniFi OS 3.0 or later
- Admin access to controller

## Main Content

Article content converted to markdown...

### Section Heading

More content...

```python
# Code blocks preserved
print("hello")
```

| Column 1 | Column 2 |
|----------|----------|
| Data     | Data     |

---
*Source: https://help.ui.com/hc/en-us/articles/123456 | Last Updated: 2024-01-15 | Article ID: 123456*
```

### 4.1.1 Structure Requirements

All documents MUST follow this predictable structure:

| Section | Required | Purpose |
|---------|----------|---------|
| Frontmatter | Yes | Metadata for filtering and indexing |
| `# Title` | Yes | Document title (H1) |
| `## Overview` | Yes | Brief summary (always present) |
| `## Prerequisites` | If applicable | Requirements before following guide |
| Main content | Yes | Original article content |
| Source footer | Yes | Attribution and traceability |

This standardization enables Claude Code to:
1. Quickly assess relevance via the Overview section
2. Understand dependencies via Prerequisites
3. Navigate predictable document structure
4. Trace back to original sources

### 4.2 Converter Implementation

**src/doc_crawler/converters/html.py:**

```python
"""
HTML to Markdown converter for documentation articles.
"""

import hashlib
import re
from dataclasses import dataclass, field
from datetime import datetime, timezone
from typing import Optional

import html2text
from bs4 import BeautifulSoup
import yaml

@dataclass
class ConversionResult:
    """Result of HTML to Markdown conversion."""
    markdown: str
    frontmatter: dict
    success: bool
    error: Optional[str] = None
    warnings: list[str] = field(default_factory=list)

@dataclass
class HTMLConverterConfig:
    """Configuration for HTML converter."""
    # html2text options
    body_width: int = 0  # 0 = no line wrapping
    ignore_links: bool = False
    ignore_images: bool = False
    ignore_emphasis: bool = False

    # Cleanup options
    remove_navigation: bool = True
    remove_scripts: bool = True
    remove_styles: bool = True

    # Output options
    include_frontmatter: bool = True
    include_source_comment: bool = False

class HTMLConverter:
    """
    Convert HTML content to Markdown with frontmatter.

    Uses html2text library for conversion with custom preprocessing
    and postprocessing for better results.
    """

    # Elements to remove before conversion
    REMOVE_SELECTORS = [
        "script",
        "style",
        "nav",
        "header.site-header",
        "footer",
        ".breadcrumbs",
        ".article-votes",
        ".article-comments",
        ".article-sidebar",
        ".share-buttons",
        ".related-articles",
        "[role='navigation']",
    ]

    def __init__(self, config: Optional[HTMLConverterConfig] = None):
        self.config = config or HTMLConverterConfig()
        self._h2t = self._create_html2text()

    def _create_html2text(self) -> html2text.HTML2Text:
        """Create configured html2text instance."""
        h = html2text.HTML2Text()

        # Basic settings
        h.body_width = self.config.body_width
        h.ignore_links = self.config.ignore_links
        h.ignore_images = self.config.ignore_images
        h.ignore_emphasis = self.config.ignore_emphasis

        # Better formatting
        h.unicode_snob = True  # Use Unicode instead of ASCII
        h.escape_snob = True   # Don't escape special characters
        h.mark_code = True     # Mark code blocks
        h.wrap_links = False   # Don't wrap links
        h.skip_internal_links = False

        # Table handling
        h.bypass_tables = False  # Convert tables

        return h

    def _preprocess_html(self, html: str, metadata: dict) -> BeautifulSoup:
        """
        Preprocess HTML before conversion.

        - Remove unwanted elements
        - Clean up structure
        - Extract any additional metadata
        """
        soup = BeautifulSoup(html, "html.parser")

        # Remove unwanted elements
        if self.config.remove_navigation:
            for selector in self.REMOVE_SELECTORS:
                for elem in soup.select(selector):
                    elem.decompose()

        if self.config.remove_scripts:
            for script in soup.find_all("script"):
                script.decompose()

        if self.config.remove_styles:
            for style in soup.find_all("style"):
                style.decompose()

        # Extract title if not in metadata
        if "title" not in metadata or not metadata["title"]:
            title_elem = soup.find("h1") or soup.find("title")
            if title_elem:
                metadata["title"] = title_elem.get_text(strip=True)

        # Handle code blocks - add language hints if possible
        for pre in soup.find_all("pre"):
            code = pre.find("code")
            if code:
                # Try to detect language from class
                classes = code.get("class", [])
                for cls in classes:
                    if cls.startswith("language-") or cls.startswith("lang-"):
                        lang = cls.split("-", 1)[1]
                        code["data-language"] = lang
                        break

        return soup

    def _postprocess_markdown(self, markdown: str) -> str:
        """
        Postprocess converted markdown.

        - Fix common conversion artifacts
        - Clean up whitespace
        - Improve formatting
        """
        # Remove excessive blank lines (more than 2 in a row)
        markdown = re.sub(r"\n{4,}", "\n\n\n", markdown)

        # Fix code block formatting - ensure language on same line as ```
        markdown = re.sub(r"```\s*\n(\w+)\n", r"```\1\n", markdown)

        # Remove trailing whitespace from lines
        markdown = "\n".join(line.rstrip() for line in markdown.split("\n"))

        # Ensure file ends with single newline
        markdown = markdown.strip() + "\n"

        return markdown

    def _generate_frontmatter(self, metadata: dict) -> str:
        """Generate YAML frontmatter from metadata."""
        # Ensure required fields
        frontmatter = {
            "source": metadata.get("source", "unknown"),
            "url": metadata.get("url", ""),
            "title": metadata.get("title", "Untitled"),
            "crawled_at": datetime.now(timezone.utc).isoformat(),
        }

        # Add optional fields if present
        for key in ["article_id", "section_id", "category_id", "updated_at", "author"]:
            if key in metadata and metadata[key]:
                frontmatter[key] = metadata[key]

        # Generate checksum from content
        if "checksum" in metadata:
            frontmatter["checksum"] = metadata["checksum"]

        # Convert to YAML
        yaml_str = yaml.dump(
            frontmatter,
            default_flow_style=False,
            allow_unicode=True,
            sort_keys=False,
        )

        return f"---\n{yaml_str}---\n\n"

    def _compute_checksum(self, content: str) -> str:
        """Compute checksum of content for change detection."""
        return hashlib.sha256(content.encode()).hexdigest()[:16]

    def _extract_overview(self, soup: BeautifulSoup, markdown: str) -> str:
        """
        Extract or generate an overview section.

        Tries to find:
        1. An existing "Overview" or "Introduction" section
        2. The first paragraph of content
        3. Meta description from HTML

        Returns:
            Overview text (1-3 sentences)
        """
        # Try to find existing overview section
        for heading in soup.find_all(["h2", "h3"]):
            text = heading.get_text(strip=True).lower()
            if text in ["overview", "introduction", "about", "summary", "description"]:
                # Get content until next heading
                content = []
                for sibling in heading.find_next_siblings():
                    if sibling.name in ["h1", "h2", "h3"]:
                        break
                    content.append(sibling.get_text(strip=True))
                if content:
                    overview = " ".join(content[:3])  # First 3 paragraphs max
                    return overview[:500] + "..." if len(overview) > 500 else overview

        # Fallback: first meaningful paragraph
        for p in soup.find_all("p"):
            text = p.get_text(strip=True)
            if len(text) > 50:  # Meaningful paragraph
                return text[:500] + "..." if len(text) > 500 else text

        # Fallback: meta description
        meta_desc = soup.find("meta", {"name": "description"})
        if meta_desc and meta_desc.get("content"):
            return meta_desc["content"]

        return "This article provides documentation on this topic."

    def _extract_prerequisites(self, soup: BeautifulSoup) -> Optional[str]:
        """
        Extract prerequisites section if present.

        Returns:
            Markdown formatted prerequisites or None
        """
        for heading in soup.find_all(["h2", "h3"]):
            text = heading.get_text(strip=True).lower()
            if text in ["prerequisites", "requirements", "before you begin", "what you need"]:
                content = []
                for sibling in heading.find_next_siblings():
                    if sibling.name in ["h1", "h2", "h3"]:
                        break
                    content.append(str(sibling))
                if content:
                    return self._h2t.handle("".join(content)).strip()
        return None

    def _generate_source_footer(self, metadata: dict) -> str:
        """Generate source attribution footer."""
        parts = []
        if metadata.get("url"):
            parts.append(f"Source: {metadata['url']}")
        if metadata.get("updated_at"):
            parts.append(f"Last Updated: {metadata['updated_at']}")
        if metadata.get("original_article_id"):
            parts.append(f"Article ID: {metadata['original_article_id']}")

        if parts:
            return "\n---\n*" + " | ".join(parts) + "*\n"
        return ""

    def _structure_document(
        self,
        title: str,
        overview: str,
        prerequisites: Optional[str],
        main_content: str,
        metadata: dict,
    ) -> str:
        """
        Assemble document with standardized structure.

        Args:
            title: Document title
            overview: Overview/summary text
            prerequisites: Optional prerequisites markdown
            main_content: Main article content markdown
            metadata: Document metadata for footer

        Returns:
            Structured markdown document
        """
        sections = []

        # Title
        sections.append(f"# {title}\n")

        # Overview (always present)
        sections.append("## Overview\n")
        sections.append(f"{overview}\n")

        # Prerequisites (if present)
        if prerequisites:
            sections.append("## Prerequisites\n")
            sections.append(f"{prerequisites}\n")

        # Main content
        sections.append(main_content)

        # Source footer
        footer = self._generate_source_footer(metadata)
        if footer:
            sections.append(footer)

        return "\n".join(sections)

    def convert(
        self,
        html: str,
        metadata: Optional[dict] = None,
    ) -> ConversionResult:
        """
        Convert HTML to Markdown with standardized structure.

        Produces documents with:
        - YAML frontmatter with metadata
        - Title (H1)
        - Overview section (always present)
        - Prerequisites section (if applicable)
        - Main content
        - Source footer

        Args:
            html: HTML content to convert
            metadata: Optional metadata to include in frontmatter

        Returns:
            ConversionResult with structured markdown content and metadata
        """
        metadata = metadata or {}
        warnings = []

        try:
            # Preprocess
            soup = self._preprocess_html(html, metadata)

            # Extract overview BEFORE removing structure
            overview = self._extract_overview(soup, "")

            # Extract prerequisites
            prerequisites = self._extract_prerequisites(soup)

            # Get article body or full content
            article_body = soup.select_one(".article-body, article, main, .content")
            if article_body:
                html_to_convert = str(article_body)
            else:
                html_to_convert = str(soup)
                warnings.append("Could not find article body, converting full HTML")

            # Convert to markdown
            main_content = self._h2t.handle(html_to_convert)

            # Postprocess
            main_content = self._postprocess_markdown(main_content)

            # Get title
            title = metadata.get("title", "Untitled")

            # Structure the document
            structured_markdown = self._structure_document(
                title=title,
                overview=overview,
                prerequisites=prerequisites,
                main_content=main_content,
                metadata=metadata,
            )

            # Compute checksum from structured content
            metadata["checksum"] = self._compute_checksum(structured_markdown)

            # Store overview in metadata for index
            metadata["overview"] = overview

            # Generate frontmatter
            frontmatter_str = ""
            if self.config.include_frontmatter:
                frontmatter_str = self._generate_frontmatter(metadata)

            # Combine frontmatter + structured content
            full_markdown = frontmatter_str + structured_markdown

            return ConversionResult(
                markdown=full_markdown,
                frontmatter=metadata,
                success=True,
                warnings=warnings,
            )

        except Exception as e:
            return ConversionResult(
                markdown="",
                frontmatter=metadata,
                success=False,
                error=str(e),
                warnings=warnings,
            )

    def convert_to_plain_text(self, html: str) -> str:
        """
        Convert HTML to plain text (no formatting).

        Useful for search indexing or summaries.
        """
        soup = BeautifulSoup(html, "html.parser")

        # Remove scripts and styles
        for elem in soup.find_all(["script", "style"]):
            elem.decompose()

        return soup.get_text(separator="\n", strip=True)


def convert_html_to_markdown(
    html: str,
    metadata: Optional[dict] = None,
    config: Optional[HTMLConverterConfig] = None,
) -> ConversionResult:
    """
    Convenience function to convert HTML to Markdown.

    Args:
        html: HTML content
        metadata: Optional metadata for frontmatter
        config: Optional converter configuration

    Returns:
        ConversionResult
    """
    converter = HTMLConverter(config)
    return converter.convert(html, metadata)
```
