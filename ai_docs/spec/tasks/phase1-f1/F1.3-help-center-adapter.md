## 1. Objective

Implement an adapter to crawl the UniFi Help Center (help.ui.com) to discover and fetch documentation articles. This adapter navigates the category/section/article hierarchy and extracts article content.

## 2. Prerequisites

- Task F1.1 (Project Setup) completed
- Task F1.2 (Fetcher) completed
- Fetcher is working and tested

## 3. Scope

### In Scope
- Discover categories, sections, and articles from Help Center
- Navigate pagination
- Extract article metadata (title, URL, category, etc.)
- Fetch article HTML content
- Handle Help Center-specific HTML structure

### Out of Scope
- HTML to Markdown conversion (F1.5)
- Saving to disk (done by main crawler)
- Authentication (Help Center is public)
- Other documentation sources (F1.4)

## 4. Implementation Requirements

### 4.1 Help Center Structure

The UI.com Help Center follows this hierarchy:

```
Category (e.g., "UniFi")
└── Section (e.g., "Getting Started")
    └── Article (e.g., "How to Set Up UniFi Network")
```

**URL Patterns:**
- Category: `https://help.ui.com/hc/en-us/categories/{id}-{slug}`
- Section: `https://help.ui.com/hc/en-us/sections/{id}-{slug}`
- Article: `https://help.ui.com/hc/en-us/articles/{id}-{slug}`

### 4.3 HTTP Request Configuration

The Help Center (help.ui.com) is built on Zendesk and may block requests that lack proper headers. Configure the Fetcher with:

```python
# Default headers for Help Center requests
HELP_CENTER_HEADERS = {
    "User-Agent": "UniFi-Doc-Crawler/1.0 (+https://github.com/yourrepo; for offline documentation)",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "en-US,en;q=0.9",
    "Accept-Encoding": "gzip, deflate, br",
    "Connection": "keep-alive",
    "Cache-Control": "no-cache",
}

# The Fetcher should:
# 1. Use these headers for all requests to help.ui.com
# 2. Maintain session cookies across requests (httpx handles this with Client)
# 3. Handle 403 responses by adding a small delay and retrying
# 4. Respect rate limits more conservatively (0.5 req/sec recommended)
```

**Note:** The 403 response from help.ui.com is typically due to missing User-Agent or anti-bot measures. Using a descriptive User-Agent and maintaining session cookies should resolve this.

### 4.4 HTML Parsing (Zendesk Structure)

The Help Center uses Zendesk's standard template structure. Key CSS selectors:

**Category Page:**
```html
<!-- Category contains sections -->
<section class="section">
  <h2 class="section-tree-title">
    <a href="/hc/en-us/sections/123-Section-Name">Section Name</a>
  </h2>
</section>
```

**Section Page:**
```html
<ul class="article-list">
  <li class="article-list-item">
    <a href="/hc/en-us/articles/456-Article-Title">Article Title</a>
  </li>
</ul>
<!-- Pagination -->
<nav class="pagination">
  <a class="pagination-next-link" href="?page=2" rel="next">Next</a>
</nav>
```

**Article Page (Zendesk Template):**
```html
<nav class="sub-nav">
  <!-- Contains breadcrumbs and subscribe - EXCLUDE -->
</nav>
<article class="article">
  <header class="article-header">
    <h1 class="article-title">Article Title</h1>
    <!-- Author info, avatar, date -->
  </header>
  <div class="article-body markdown">
    <!-- Main content - THIS IS WHAT WE WANT -->
    <!-- May contain tables wrapped in <figure class="wysiwyg-table"> -->
  </div>
  <footer class="article-footer">
    <!-- Voting buttons, feedback - EXCLUDE -->
  </footer>
</article>
<div class="article-sidebar">
  <!-- Related articles - EXCLUDE -->
</div>
```

**CSS Selectors Summary:**
| Element | Primary Selector | Fallback Selector |
|---------|-----------------|-------------------|
| Article body | `.article-body` | `.article-body.markdown`, `article .content` |
| Article title | `h1.article-title` | `.article-header h1`, `article h1` |
| Last updated | `time[datetime]` | `.article-meta time` |
| Author | `.article-author` | `.author-name` |
| Breadcrumbs | `.breadcrumbs` | `.sub-nav .breadcrumb` |

**Elements to EXCLUDE when extracting content:**
- `.sub-nav` (navigation)
- `.breadcrumbs` (breadcrumb trail)
- `.article-footer` (voting buttons)
- `.article-sidebar` (related articles)
- `.article-votes` (helpful/not helpful)
- `.article-comments` (comments section)
- `script`, `style` (always remove)

### 4.5 Adapter Implementation

```python
class HelpCenterAdapter(BaseAdapter):
    """
    Adapter for crawling the UniFi Help Center.

    Discovers articles by:
    1. Starting from configured category URLs
    2. Finding all sections within each category
    3. Finding all articles within each section
    4. Handling pagination for sections with many articles
    """

    name = "help_center"

    def __init__(self, config: HelpCenterConfig, fetcher: Fetcher):
        self.config = config
        self.fetcher = fetcher
        self.base_url = config.base_url.rstrip("/")

    def _build_category_url(self, category_id: str) -> str:
        """Build URL for a category page."""
        return f"{self.base_url}/categories/{category_id}"

    def _extract_id_from_url(self, url: str) -> str:
        """Extract ID from a Help Center URL."""
        # URL format: /hc/en-us/articles/123456-slug
        path = urlparse(url).path
        parts = path.split("/")
        for part in parts:
            if "-" in part and part.split("-")[0].isdigit():
                return part.split("-")[0]
        return ""

    async def _fetch_and_parse(self, url: str) -> Optional[BeautifulSoup]:
        """Fetch URL and parse as HTML."""
        text, result = await self.fetcher.get_text(url)
        if not result.success:
            return None
        return BeautifulSoup(text, "html.parser")

    async def _discover_sections(self, category_url: str) -> AsyncIterator[HelpCenterSection]:
        """Discover all sections in a category."""
        soup = await self._fetch_and_parse(category_url)
        if not soup:
            return

        category_id = self._extract_id_from_url(category_url)

        # Find section links
        sections = soup.select("section.section, .section-tree-title a")
        for elem in sections:
            if elem.name == "a":
                link = elem
            else:
                link = elem.select_one("a")

            if link and link.get("href"):
                href = link["href"]
                if "/sections/" in href:
                    full_url = urljoin(self.base_url, href)
                    section_id = self._extract_id_from_url(href)
                    yield HelpCenterSection(
                        id=section_id,
                        name=link.get_text(strip=True),
                        url=full_url,
                        category_id=category_id,
                    )

    async def _discover_articles_in_section(
        self,
        section: HelpCenterSection,
        max_pages: int = 10,
    ) -> AsyncIterator[HelpCenterArticle]:
        """Discover all articles in a section, handling pagination."""
        url = section.url
        pages_fetched = 0

        while url and pages_fetched < max_pages:
            soup = await self._fetch_and_parse(url)
            if not soup:
                break

            pages_fetched += 1

            # Find article links
            articles = soup.select(".article-list-item a, ul.article-list a")
            for link in articles:
                href = link.get("href")
                if href and "/articles/" in href:
                    full_url = urljoin(self.base_url, href)
                    article_id = self._extract_id_from_url(href)
                    yield HelpCenterArticle(
                        id=article_id,
                        title=link.get_text(strip=True),
                        url=full_url,
                        section_id=section.id,
                        category_id=section.category_id,
                    )

            # Check for next page
            next_link = soup.select_one(".pagination-next-link, a[rel='next']")
            if next_link and next_link.get("href"):
                url = urljoin(url, next_link["href"])
            else:
                url = None

    async def discover(self) -> AsyncIterator[CrawlItem]:
        """
        Discover all articles to crawl from configured categories.

        Yields CrawlItem for each article found.
        """
        for category_id in self.config.categories:
            category_url = self._build_category_url(category_id)

            async for section in self._discover_sections(category_url):
                async for article in self._discover_articles_in_section(section):
                    yield CrawlItem(
                        url=article.url,
                        item_type="article",
                        metadata={
                            "article_id": article.id,
                            "title": article.title,
                            "section_id": article.section_id,
                            "category_id": article.category_id,
                            "source": self.name,
                        },
                    )

    async def fetch(self, item: CrawlItem) -> CrawlResult:
        """
        Fetch article content.

        Returns CrawlResult with HTML content and extracted metadata.
        """
        text, result = await self.fetcher.get_text(item.url)

        if not result.success:
            return CrawlResult(
                url=item.url,
                content="",
                content_type="text/html",
                metadata=item.metadata,
                success=False,
                error=result.error,
            )

        # Parse and extract article content
        soup = BeautifulSoup(text, "html.parser")

        # Remove elements we don't want before extracting content
        for selector in [".sub-nav", ".breadcrumbs", ".article-footer",
                         ".article-sidebar", ".article-votes", ".article-comments",
                         "script", "style"]:
            for elem in soup.select(selector):
                elem.decompose()

        # Extract article body (Zendesk structure)
        article_body = soup.select_one(".article-body, .article-body.markdown, article .content")
        if article_body:
            content = str(article_body)
        else:
            # Fallback: try to get main content
            main = soup.select_one("article, main, .main-content")
            content = str(main) if main else text

        # Extract additional metadata
        metadata = dict(item.metadata)

        # Title
        title_elem = soup.select_one("h1.article-title, article h1")
        if title_elem:
            metadata["title"] = title_elem.get_text(strip=True)

        # Last updated
        time_elem = soup.select_one("time[datetime]")
        if time_elem:
            metadata["updated_at"] = time_elem.get("datetime")

        # Author
        author_elem = soup.select_one(".article-author, .author-name")
        if author_elem:
            metadata["author"] = author_elem.get_text(strip=True)

        return CrawlResult(
            url=item.url,
            content=content,
            content_type="text/html",
            metadata=metadata,
            success=True,
        )

    async def fetch_article(self, article: HelpCenterArticle) -> Optional[ArticleContent]:
        """
        Convenience method to fetch full article content.

        Returns ArticleContent with both HTML and text content.
        """
        item = CrawlItem(
            url=article.url,
            item_type="article",
            metadata={
                "article_id": article.id,
                "title": article.title,
                "section_id": article.section_id,
                "category_id": article.category_id,
            },
        )

        result = await self.fetch(item)
        if not result.success:
            return None

        # Extract plain text
        soup = BeautifulSoup(result.content, "html.parser")
        text_content = soup.get_text(separator="\n", strip=True)

        return ArticleContent(
            article=article,
            html_content=result.content,
            text_content=text_content,
            metadata=result.metadata,
        )
```

### 4.6 Semantic Path Generation

Files should be named using semantic, slugified names organized by topic rather than article IDs. This enables effective discovery via Glob patterns when used by agentic frameworks like Claude Code.

**Current (avoid):**
```
help-center/115004076147-How-to-Create-a-VLAN.md
```

**Preferred:**
```
help-center/vlans/creating-vlans.md
help-center/firewall/traffic-rules-basics.md
help-center/switching/port-profiles.md
```

**Add to src/doc_crawler/paths.py:**

```python
"""
Semantic path generation for documentation files.
"""

import re
from typing import Optional

# Topic classification based on keywords in title/content
TOPIC_KEYWORDS = {
    "vlans": ["vlan", "network", "subnet", "dhcp", "ip range"],
    "firewall": ["firewall", "traffic", "rule", "block", "allow", "port forwarding", "threat management"],
    "switching": ["switch", "port", "poe", "lacp", "trunk", "stp", "aggregation"],
    "wireless": ["wifi", "wireless", "ssid", "ap", "access point", "wlan", "radio"],
    "vpn": ["vpn", "wireguard", "ipsec", "openvpn", "teleport", "site-to-site"],
    "gateway": ["gateway", "wan", "internet", "routing", "nat", "isp"],
    "clients": ["client", "device", "fingerprint", "block client", "alias"],
    "system": ["backup", "restore", "update", "firmware", "controller", "adopt", "migrate", "console"],
    "troubleshooting": ["troubleshoot", "debug", "log", "issue", "problem", "fix", "error"],
}

TOPIC_DESCRIPTIONS = {
    "vlans": "VLAN and network configuration",
    "firewall": "Firewall rules and traffic management",
    "switching": "Switch configuration and port management",
    "wireless": "WiFi and access point configuration",
    "vpn": "VPN setup and remote access",
    "gateway": "Gateway, WAN, and routing configuration",
    "clients": "Client device management",
    "system": "System administration and maintenance",
    "troubleshooting": "Debugging and problem resolution",
    "general": "General documentation",
}

def slugify(text: str) -> str:
    """Convert text to URL-friendly slug."""
    # Lowercase
    slug = text.lower()
    # Remove special characters
    slug = re.sub(r"[^\w\s-]", "", slug)
    # Replace whitespace with hyphens
    slug = re.sub(r"[\s_]+", "-", slug)
    # Remove consecutive hyphens
    slug = re.sub(r"-+", "-", slug)
    # Trim hyphens from ends
    slug = slug.strip("-")
    # Limit length
    if len(slug) > 60:
        slug = slug[:60].rsplit("-", 1)[0]
    return slug

def classify_topic(title: str, content: str = "") -> str:
    """
    Classify article into a topic based on keywords.

    Args:
        title: Article title
        content: Optional article content for better classification

    Returns:
        Topic name (e.g., "vlans", "firewall", "general")
    """
    text = f"{title} {content}".lower()

    scores = {}
    for topic, keywords in TOPIC_KEYWORDS.items():
        score = sum(1 for kw in keywords if kw in text)
        if score > 0:
            scores[topic] = score

    if scores:
        return max(scores, key=scores.get)
    return "general"

def generate_semantic_path(
    article_id: str,
    title: str,
    content: str = "",
    base_dir: str = "help-center",
) -> str:
    """
    Generate semantic file path for an article.

    Args:
        article_id: Original article ID (preserved in frontmatter for traceability)
        title: Article title
        content: Article content (for better classification)
        base_dir: Base directory for output

    Returns:
        Semantic path like "help-center/vlans/creating-vlans.md"
    """
    topic = classify_topic(title, content)
    slug = slugify(title)
    return f"{base_dir}/{topic}/{slug}.md"

def extract_keywords(title: str, content: str = "") -> list[str]:
    """
    Extract relevant keywords from title and content.

    Args:
        title: Article title
        content: Article content

    Returns:
        List of keywords (max 10)
    """
    text = f"{title} {content}".lower()

    # Common UniFi keywords to look for
    keyword_candidates = [
        "vlan", "network", "firewall", "switch", "port", "wifi", "wireless",
        "ssid", "vpn", "gateway", "wan", "dhcp", "dns", "nat", "routing",
        "qos", "traffic", "rule", "client", "device", "ap", "controller",
        "backup", "restore", "update", "firmware", "adopt", "provision",
        "poe", "lacp", "trunk", "stp", "radius", "certificate", "ssl",
        "wireguard", "ipsec", "teleport", "threat", "dpi", "ids", "ips",
    ]

    found = [kw for kw in keyword_candidates if kw in text]
    return found[:10]
```
