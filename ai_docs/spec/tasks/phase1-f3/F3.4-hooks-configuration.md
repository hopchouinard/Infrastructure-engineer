## 4. Background: Claude Code Hooks

### 4.1 Hook Types

Hooks are configured in `.claude/settings.json` and can trigger on:

| Event | When it Fires |
|-------|--------------|
| `PreToolUse` | Before any tool is called |
| `PostToolUse` | After any tool completes |
| `UserPromptSubmit` | When user sends a message |
| `Notification` | When Claude generates a notification |
| `Stop` | When session is about to end |
| `SubagentStop` | When a subagent finishes |
| `SessionStart` | When a new session begins |

### 4.2 Hook Configuration Format

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "pattern|pattern",
        "hooks": [
          {
            "type": "command",
            "command": "path/to/script.sh"
          }
        ]
      }
    ]
  }
}
```

### 4.3 Hook Execution Modes

| Type | Description | Use Case |
|------|-------------|----------|
| `command` | Run shell command | Logging, validation, notifications |
| `prompt` | Let Claude decide using LLM | Context-aware decisions |

### 4.4 Hook Input

Hook scripts receive JSON on stdin with context:
```json
{
  "tool_name": "unifi_create_network",
  "tool_input": { "name": "IoT", "vlan_id": 40 },
  "result": { "success": true, "rollback_id": "..." }
}
```

### 5.2 Post-Change Logging Hook

**File: `.claude/hooks/post-change-log.sh`**

```bash
#!/usr/bin/env bash
#
# Post-change logging hook for UniFi infrastructure changes
# Logs all configuration changes to a local file for audit trail
#
# Input (stdin): JSON with tool_name, tool_input, result
# Output (stdout): Message for Claude to see
#

set -euo pipefail

# Configuration
LOG_DIR="${CLAUDE_PROJECT_DIR:-.}/.claude/logs"
LOG_FILE="${CLAUDE_CHANGE_LOG:-$LOG_DIR/infrastructure-changes.json}"
MAX_LOG_SIZE=10485760  # 10MB

# Ensure log directory exists
mkdir -p "$LOG_DIR"

# Rotate log if too large
if [[ -f "$LOG_FILE" ]] && [[ $(stat -f%z "$LOG_FILE" 2>/dev/null || stat -c%s "$LOG_FILE" 2>/dev/null) -gt $MAX_LOG_SIZE ]]; then
    mv "$LOG_FILE" "$LOG_FILE.old"
fi

# Read input
INPUT=$(cat)

# Parse JSON (requires jq)
if ! command -v jq &> /dev/null; then
    echo "Warning: jq not installed, logging disabled"
    exit 0
fi

TOOL_NAME=$(echo "$INPUT" | jq -r '.tool_name // "unknown"')
SUCCESS=$(echo "$INPUT" | jq -r '.result.success // "unknown"')
ROLLBACK_ID=$(echo "$INPUT" | jq -r '.result.rollback_id // "none"')
TOOL_INPUT=$(echo "$INPUT" | jq -c '.tool_input // {}')

# Get timestamp
TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")

# Create log entry
LOG_ENTRY=$(jq -nc \
    --arg ts "$TIMESTAMP" \
    --arg tool "$TOOL_NAME" \
    --arg success "$SUCCESS" \
    --arg rollback "$ROLLBACK_ID" \
    --argjson input "$TOOL_INPUT" \
    '{
        timestamp: $ts,
        tool: $tool,
        success: $success,
        rollback_id: $rollback,
        input: $input
    }')

# Append to log
echo "$LOG_ENTRY" >> "$LOG_FILE"

# Output for Claude
if [[ "$SUCCESS" == "true" ]]; then
    if [[ "$ROLLBACK_ID" != "none" && "$ROLLBACK_ID" != "null" ]]; then
        echo "📝 Change logged. Rollback ID: $ROLLBACK_ID (valid 60 min)"
    else
        echo "📝 Change logged."
    fi
else
    echo "📝 Failed operation logged."
fi
```

### 5.3 Pre-Delete Network Validation

**File: `.claude/hooks/pre-delete-network.sh`**

```bash
#!/usr/bin/env bash
#
# Pre-delete-network validation hook
# Blocks deletion of protected networks
#
# Input (stdin): JSON with tool_name, tool_input
# Exit 0: Allow the operation
# Exit non-zero: Block the operation (message shown to user)
#

set -euo pipefail

# Read input
INPUT=$(cat)

# Parse network identifier
IDENTIFIER=$(echo "$INPUT" | jq -r '.tool_input.identifier // ""')
IDENTIFIER_LOWER=$(echo "$IDENTIFIER" | tr '[:upper:]' '[:lower:]')

# Protected networks (cannot be deleted)
PROTECTED_NETWORKS=("default" "lan" "management" "wan" "wan2")

# Check if trying to delete a protected network
for protected in "${PROTECTED_NETWORKS[@]}"; do
    if [[ "$IDENTIFIER_LOWER" == "$protected" ]]; then
        echo "🚫 BLOCKED: Cannot delete protected network '$IDENTIFIER'"
        echo ""
        echo "The '$protected' network is a system network and cannot be deleted."
        echo "This would break management access to the controller."
        exit 1
    fi
done

# Check for VLAN 1 (default)
if [[ "$IDENTIFIER" == "1" ]]; then
    echo "🚫 BLOCKED: Cannot delete VLAN 1 (default network)"
    exit 1
fi

# Allow the operation
exit 0
```

### 5.4 Pre-Firewall Rule Validation

**File: `.claude/hooks/pre-firewall-rule.sh`**

```bash
#!/usr/bin/env bash
#
# Pre-firewall-rule validation hook
# Blocks overly permissive firewall rules
#
# Input (stdin): JSON with tool_name, tool_input
# Exit 0: Allow the operation
# Exit non-zero: Block the operation
#

set -euo pipefail

# Read input
INPUT=$(cat)

# Parse rule parameters
ACTION=$(echo "$INPUT" | jq -r '.tool_input.action // ""')
SOURCE_TYPE=$(echo "$INPUT" | jq -r '.tool_input.source_type // ""')
SOURCE_NETWORK=$(echo "$INPUT" | jq -r '.tool_input.source_network // ""')
DEST_TYPE=$(echo "$INPUT" | jq -r '.tool_input.destination_type // ""')
DEST_NETWORK=$(echo "$INPUT" | jq -r '.tool_input.destination_network // ""')
PROTOCOL=$(echo "$INPUT" | jq -r '.tool_input.protocol // "all"')

# Block "allow any to any" rules
if [[ "$ACTION" == "accept" ]]; then
    is_any_source=false
    is_any_dest=false

    # Check source
    if [[ -z "$SOURCE_TYPE" || "$SOURCE_TYPE" == "any" ]]; then
        if [[ -z "$SOURCE_NETWORK" ]]; then
            is_any_source=true
        fi
    fi

    # Check destination
    if [[ -z "$DEST_TYPE" || "$DEST_TYPE" == "any" ]]; then
        if [[ -z "$DEST_NETWORK" ]]; then
            is_any_dest=true
        fi
    fi

    # Block if both source and dest are "any" and protocol is "all"
    if [[ "$is_any_source" == "true" && "$is_any_dest" == "true" && "$PROTOCOL" == "all" ]]; then
        echo "🚫 BLOCKED: Cannot create 'allow any to any' firewall rule"
        echo ""
        echo "This rule would allow all traffic from anywhere to anywhere,"
        echo "effectively bypassing all network segmentation."
        echo ""
        echo "Please specify:"
        echo "  - A specific source network or IP"
        echo "  - A specific destination network or IP"
        echo "  - Or specific protocols/ports"
        exit 1
    fi
fi

# Allow the operation
exit 0
```

### 5.5 High-Risk Notification Hook

**File: `.claude/hooks/high-risk-notify.sh`**

```bash
#!/usr/bin/env bash
#
# High-risk operation notification hook
# Logs high-risk operations to a separate file and optionally notifies
#
# This hook runs AFTER high-risk operations complete
#

set -euo pipefail

# Configuration
LOG_DIR="${CLAUDE_PROJECT_DIR:-.}/.claude/logs"
ALERT_FILE="$LOG_DIR/high-risk-alerts.log"

mkdir -p "$LOG_DIR"

# Read input
INPUT=$(cat)

TOOL_NAME=$(echo "$INPUT" | jq -r '.tool_name // "unknown"')
SUCCESS=$(echo "$INPUT" | jq -r '.result.success // "unknown"')
TOOL_INPUT=$(echo "$INPUT" | jq -c '.tool_input // {}')
TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")

# Determine risk description
case "$TOOL_NAME" in
    *delete_network*)
        RISK_DESC="Network deletion"
        ;;
    *create_firewall_rule*)
        RISK_DESC="Firewall rule creation"
        ;;
    *delete_firewall_rule*)
        RISK_DESC="Firewall rule deletion"
        ;;
    *)
        RISK_DESC="High-risk operation"
        ;;
esac

# Log to alert file
ALERT_ENTRY=$(jq -nc \
    --arg ts "$TIMESTAMP" \
    --arg tool "$TOOL_NAME" \
    --arg desc "$RISK_DESC" \
    --arg success "$SUCCESS" \
    --argjson input "$TOOL_INPUT" \
    '{
        timestamp: $ts,
        risk_type: $desc,
        tool: $tool,
        success: $success,
        parameters: $input
    }')

echo "$ALERT_ENTRY" >> "$ALERT_FILE"

# Output notification
if [[ "$SUCCESS" == "true" ]]; then
    echo "⚠️ High-risk operation completed: $RISK_DESC"
else
    echo "⚠️ High-risk operation FAILED: $RISK_DESC"
fi

# Future: Add external notification here
# Example: curl -X POST "https://ntfy.sh/your-topic" -d "$RISK_DESC completed"
```

### 5.6 Log Viewer Script

**File: `.claude/hooks/view-logs.sh`**

```bash
#!/usr/bin/env bash
#
# View recent infrastructure change logs
# Usage: ./view-logs.sh [--alerts] [--tail N]
#

LOG_DIR="${CLAUDE_PROJECT_DIR:-.}/.claude/logs"
CHANGE_LOG="${CLAUDE_CHANGE_LOG:-$LOG_DIR/infrastructure-changes.json}"
ALERT_LOG="$LOG_DIR/high-risk-alerts.log"

SHOW_ALERTS=false
TAIL_LINES=10

# Parse arguments
while [[ $# -gt 0 ]]; do
    case $1 in
        --alerts)
            SHOW_ALERTS=true
            shift
            ;;
        --tail)
            TAIL_LINES="$2"
            shift 2
            ;;
        *)
            shift
            ;;
    esac
done

if [[ "$SHOW_ALERTS" == "true" ]]; then
    LOG_FILE="$ALERT_LOG"
    echo "=== High-Risk Alerts (last $TAIL_LINES) ==="
else
    LOG_FILE="$CHANGE_LOG"
    echo "=== Infrastructure Changes (last $TAIL_LINES) ==="
fi

if [[ ! -f "$LOG_FILE" ]]; then
    echo "No logs found at $LOG_FILE"
    exit 0
fi

# Display formatted logs
tail -n "$TAIL_LINES" "$LOG_FILE" | while read -r line; do
    echo "$line" | jq -r '[.timestamp, .tool, .success] | @tsv' 2>/dev/null || echo "$line"
done
```

## 9. Implementation Notes

### 9.1 Hook Script Requirements

All hook scripts must:
- Start with `#!/usr/bin/env bash`
- Be executable (`chmod +x`)
- Read JSON from stdin
- Exit 0 to allow, non-zero to block (for pre-hooks)
- Write messages to stdout (shown to Claude/user)
- Handle errors gracefully

### 9.2 JSON Processing

Scripts use `jq` for JSON parsing. If jq is not installed:
- Log a warning
- Skip processing
- Don't crash

### 9.3 Log Storage

Logs are stored in `.claude/logs/`:
- `infrastructure-changes.json` - All configuration changes (JSON Lines format)
- `high-risk-alerts.log` - High-risk operations only

Consider adding to `.gitignore` if logs contain sensitive info.
